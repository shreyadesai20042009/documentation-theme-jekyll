# Documentation Theme – Jekyll

This is a documentation website theme built using Jekyll.
It can be used to create clean and simple documentation sites.

## Features
- Clean documentation layout
- Built with Jekyll
- Easy to customize
- Markdown support

## Technologies Used
- Jekyll
- HTML
- CSS
- Markdown

## How to Run the Project

1. Install Jekyll
2. Clone the repository
   git clone https://github.com/<Your Github User Name>/documentation-theme-jekyll.git
3. Go to the project folder
4. Run the site using:
   bundle exec jekyll serve
5. Open browser and go to:
   http://localhost:4000

   ## Folder Structure
- _docs → Documentation pages (main content)
- _layouts → Page layouts
- _includes → Reusable UI components
- _data → Navigation and configuration data
- assets → CSS, JavaScript, images, fonts
- pages → Extra site pages
- _posts → Blog or update posts
- pdf / pdfconfigs → PDF documentation generation
